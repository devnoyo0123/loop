구현 노트 (B안 선택 시)

  • 소리 반복 — 안드로이드 insistent 알림 플래그: 알림을 닫을 때까지 알림음 반복. 네이티브 코드 불필요
  • 알람 볼륨 — audioAttributes = ALARM: 무음 모드에서도 울리고 볼륨도 알람 볼륨을 따름
  • 전체 화면 — fullScreenIntent + manifest에 USE_FULL_SCREEN_INTENT 권한. 안드로이드 14+는 사용자가 "알람 및 리마인더" 권한을 허용해야 해서, 앱에서 안내 화면으로 데려다줌. 권한이 없으면 자동으로 A안처럼 폴백 — 깨지지 않고 알림으로만 울림
  • 스누즈 — 알림 액션 "10분 후 다시": 기존 "확인" 액션 옆에 추가, 누르면 10분 뒤로 재예약
  • 저장 구조 — logs에 루프별 플래그 컬럼(loop_alarm) 하나 추가. 기존 DB 자동 마이그레이션
  • 한계 — 방해금지(DND) 예외는 시계 앱처럼 자동이 아니라 사용자 허용 필요
  • 확인 방법 — 구현 후 폰 연결해서 실제 알림/알람을 각각 발화시켜 체감 비교 가능
