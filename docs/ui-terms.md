# UI 용어 정리

> Loop 앱을 만들면서 쓰는 UI 관련 용어를 인테리어 비유와 함께 정리한 문서.

## 한눈에 보는 층구조

```
큰 것 (추상적) ──────────────────────────── 작은 것 (구체적)

디자인 무드 > 디자인 시스템 > 템플릿 > 컴포넌트 라이브러리 > 테마 > 컴포넌트(위젯)
```

## 용어표

| 용어 | 뜻 | 인테리어 비유 | 예시 |
|---|---|---|---|
| **위젯/컴포넌트** | 버튼, 입력창, 카드 같은 UI 부품 하나하나 | 의자, 책상, 서랍 | `Button`, `TextField`, `Card` |
| **컴포넌트 라이브러리 (UI 킷)** | 부품들을 모아놓은 패키지. "UI 라이브러리"라고도 함 | 이케아 (가구 브랜드 통째로) | **Forui**, Material, Cupertino |
| **테마 / 디자인 토큰** | 컴포넌트에 입히는 색·폰트·간격 값 | 가구의 색상·소재 선택 | 다크 테마, Flutter의 `ThemeData` |
| **템플릿** | 부품을 조립해놓은 완성된 화면 예시 | "꾸며진 방" 예시 사진 | 로그인 화면 템플릿, 채팅 UI 템플릿 |
| **디자인 시스템** | 컴포넌트 + 토큰 + 사용 규칙까지 포함한 설계 규격 | 이케아의 카탈로그 + 조립 가이드 전체 | shadcn/ui, Material Design |
| **디자인 무드/스타일** | 전체적인 분위기 방향 | "차분한 모던" vs "따뜻한 빈티지" | 미니멀 다크, 종이 질감 |

## Loop 앱에 대입하면

| 항목 | Loop에서의 결정 |
|---|---|
| 위젯 | 로그 카드, 입력창, 시간 스테퍼 (직접 조립) |
| 컴포넌트 라이브러리 | **Forui** ✅ (shadcn 감성의 부품 상자) |
| 테마/토큰 | `lib/design/tokens.dart`에 정의 (아직 미정) |
| 템플릿 | 불필요 — 화면이 1~2개뿐이라 직접 조립 |
| 디자인 시스템 | Forui + 우리 토큰을 합친 것 |
| 무드 | 유일하게 남은 미정 항목 |

## 핵심 문장

> **컴포넌트(UI 부품)는 라이브러리에서 가져오고, 그에 톤을 입히는 게 테마.**

## 관련 패키지 (pubspec에 추가됨)

- `forui` — shadcn/ui 스타일을 Flutter로 포팅한 컴포넌트 라이브러리
- `flutter_animate` — 애니메이션 보조 (메아리/루프 효과용)
- `flutter_local_notifications` — 로컬 알림 (루프가 돌아오는 시점 알려주기)
- `timezone` — 알림 예약 시각 처리
