# Loop 성장 기획 백로그 — "더 많은 사람을 훅하기"

> 작성: 2026-10-25 · v1(기록 흐름 통계) + v2(그때의 나 · 공유 카드 · 첫 루프 스타터 팩) 구현 완료
> 전제: 로컬 퍼스트(서버 없음) 원칙은 유지. 릴리즈 직전(AdMob 네이티브 광고 확정).

각 아이디어를 훅 모형(트리거 → 액션 → 가변 보상 → 투자, Nir Eyal)으로 평가하고,
아래 4개 기준으로 스코어링했다.

- **개념 적합성(Concept)**: "과거의 내가 다시 찾아온다"는 Loop만의 정체성을 강화하는가
- **리텐션(Retention)**: D7/D30 재방문을 실제로 끌어당기는가
- **유입(Acquisition)**: 신규 사용자를 데려오는가
- **비용(Cost)**: 이 코드베이스에서의 구현 비용 (낮을수록 좋음)

## 후보 리스트

### 1. 📈 기록 흐름 통계 (Loop Insights) — **선정**

총 기록·기록한 날·연속(스트릭)·최장 연속, 최근 15주 히트맵, "생각이 N번 다시
돌아왔어요"(단발 복습 + 반복 발화 합산), 가장 많이 이어진 사슬 TOP 3.

- 훅: **투자의 가시화** — 쌓은 기록이 보상으로 돌아오는 순간을 만든다. 진행
  효과(내 목표에 가까워지고 있다)는 검증된 리텐션 장치(GitHub 잔디, Duolingo).
- Loop 특화: 일반 습관앱 통계가 아니라 "사슬·돌아온 횟수"를 보여준다 — 차별점
  그 자체를 숫자로 증명 ("당신의 생각이 217번 돌아왔습니다").
- 데이터가 이미 다 있다(`created_at`, `root_id`, `loop_count`, `fire_count`) —
  신규 수집·권한·플랫폼 채널 전혀 없음. 로컬 퍼스트 100% 준수.
- 광고 시너지: 통계 확인 = 쓸 말이 없는 날에도 앱을 여는 이유 → 세션 빈도 ↑ =
  타임라인 광고 노출 ↑.
- 스토어 스크린샷 소재 즉시 확보(릴리즈 직전이라 즉효).
- 단점: 그 자체로는 신규 유입을 만들지 못함 → 공유 카드(4번)로 이어지는 전단계.

### 2. 🏠 홈 화면 위젯 — 차순위 (로드맵 2단계)

홈 화면에 "과거의 나 한 줄"(과거 로그 미러) + 빠른 작성 버튼.

- 훅: **외부 트리거**의 왕 — 하루 수십 번 보는 홈 화면에 존재감. 위젯 앱들의
  D30 리텐션 기여는 업계에서 검증됨.
- Loop 특화: 위젯이 곧 "과거의 나가 지금 찾아온다"의 상시 노출.
- 단점: platform channel + AppWidgetProvider(안드로이드) + 갱신 전략 —
  인큐베이션 1호로는 스코프가 크고 네이티브 코드 버그 리스크. 통계가 먼저
  "위젯에 보여줄 것"을 만들어 준다.

### 3. 📮 그때의 나 (On this day) — 차순위 (로드맵 3단계)

매일 아침, 1주/1개월/1년 전 오늘의 기록을 알림으로 다시 들려준다.

- 훅: **감정 보상(향수)** + 데일리 트리거. 콘셉트 적합성은 전 후보 중 최고 —
  "과거의 내가 다시 찾아온다"를 사용자가 설정 없이 경험한다.
- 단점: 기록이 쌓인 사용자에게만 작동(콜드스타트에 무력), 알림 피로 리스크,
  Time-machine 쿼리·데일리 예약 로직 필요. 3개월 뒤의 신규 유저에게도
  유의미하려면 "1주 전부터" 같은 완화 설계가 필요.

### 4. 🖼 공유 카드 — 통계 완성 후 (로드맵 2단계)

히트맵/사슬을 예쁜 이미지로 export → 인스타 스토리·커뮤니티 공유.

- 훅: **바이럴 루프** — 유저가 만든 콘텐츠가 광고가 된다. 유입 임팩트 최대.
- 단점: 보여줄 통계가 없으면 카드도 없다 — 1번의 직계 후속. RepaintBoundary
  캡처 + 공유 시트는 저비용이므로 1번 완성 직후 붙이기 좋음.

### 5. 🌱 첫 루프 스타터 팩 (콜드스타트 개선)

온보딩에서 "오늘 배운 것", "감사 3개", "2시간마다 물" 등 즉시 걸 수 있는
루프 프리셋 제안.

- 훅: 첫 세션에서 핵심 사이클(쓰기 → 알림 → 이어쓰기)을 5분 안에 체감시켜
  D1 이탈 방지.
- 단점: 앱이 아직 텅 비었을 때만 쓰이는 일회성. 프리셋 큐레이션 품질이
  전부라 에디토리얼 작업 필요.

### 6. 🎲 무작위 재회 (셔플)

탭하면 과거 랜덤 기록 하나가 돌아온다.

- 훅: **가변 보상**(슬롯머신) — 저렴하게 빌드 가능.
- 단점: 깊이가 얕고 "왜 이걸 보여줬지?" 신뢰 리스크. 3번(그때의 나)이 같은
  보상을 더 좋은 형태로 준다.

### 7. 🎙 음성 로그

말로 남기면 텍스트로 기록.

- 훅: 액션 마찰 감소 — 쓰기 귀찮은 순간(걸으면서)을 잡는다.
- 단점: 온디바이스 STT 품질 편차, 권한, 스코프 큼. 차별점은 아니고
  편의 기능. 성장 축보다 완성도 축.

### 8. 🔗 공유 URL 스킴 (특정 사슬 공유·딥링크)

사슬 하나를 읽기 전용 링크로 공유.

- 단점: 서버리스 원칙과 충돌(링크에 데이터 실으려면 호스팅 필요) —
  데이터가 로컬을 떠난다. 기각.

## 인큐베이팅 v2 (2026-10-25) — 그때의 나 · 공유 카드 · 첫 루프 스타터 팩

사용자 승인으로 후보 3번·4번·5번을 추가 구현했다.

### 3. 📮 그때의 나 (구현)

- **동작**: 오늘부터 8일 치 "아침 9시" 알림을 미리 예약 — 각 날짜의
  1주/1개월/1년 전 오늘 기록 중 가장 먼 재회(1년→1개월→1주)를 골라
  "원문 미리보기 · 1년 전 오늘" 형태로 보낸다. 그날의 과거는 예약 시점에
  이미 과거라 미리 계산해도 정확하다. 탭하면 그 기록이 있는 날로 이동.
- **월·년 날짜 계산**: 말일 클램프 — 3/31의 한 달 전은 2/28, 2/29의 1년
  전은 2/28 (Dart 생성자는 넘친 날짜를 다음 달로 굴리므로 직접 계산).
- **채널 분리**: 'onthisday' 채널, `확인` 액션 없음 — 조용한 아침 인사.
- **설정**: 설정 시트 토글(기본 ON). 하루 한 번 + 설정 변경 때만 재예약.
- **파일**: `lib/utils/on_this_day.dart`(순수), `LoopDb.logsOnDay`,
  `LoopNotifications.scheduleOnThisDay`, 타임라인 `_syncOnThisDay`.

### 4. 🖼 공유 카드 (구현)

- **동작**: 통계 시트 공유 버튼 → 540×675(4:5) 카드를 오버레이 화면 밖에
  그려 1080×1350 PNG로 캡처 → 시스템 공유 시트. 이미지는 전부 기기에서
  만들어진다(로컬 퍼스트 유지).
- **내용**: Loop ↩ 브랜드 · "생각이 N번 다시 돌아왔어요" · 핵심 숫자 4개 ·
  15주 히트맵 · 태그라인. 히트맵 격자는 시트와 카드가 같은 위젯
  (`lib/widgets/heatmap.dart`)을 쓴다.
- **의존성**: `share_plus 13.3.1` 추가(첫 외부 공유 의존성).

### 5. 🌱 첫 루프 스타터 팩 (구현)

- **동작**: 텅 빈 최신 타임라인에 스타터 3장 — ①10분 루프(망각곡선 첫
  단계를 그대로 체험) ②매일 밤 9시 한 줄 ③일주일 루프. 탭하면 작성 시트가
  열리고(상단에 "↩ 10분 뒤 다시 돌아와요" 배너) 저장하면 해당 루프/반복이
  첫 기록에 자동으로 걸린다. 사용자가 직접 ⏰ 예약을 골랐으면 그것이 우선.
- **파일**: `lib/utils/starters.dart`(프리셋·`nextDailyFire` 순수 계산),
  타임라인 빈 상태 + `_compose(starter:)`.

### 9. 🎥 촬영 첨부 (v9 구현 완료 — 사진·동영상)

사진·동영상 모두 시스템 카메라 인텐트 방식(권한·네이티브 촬영 코드 불필요,
셔터음은 기기 카메라 앱 정책 — 무음 기능은 넣지 않기로 결정).

**동영상 v1 (2026-10-30 구현)**:
- 촬영: 작성 시트 🎬 버튼 → 시스템 카메라 동영상 모드, 최대 1분 제한.
- 저장: `log_videos` 테이블(DB엔 파일명·크기 메타만) + `VideoStore`
  (app dir/videos/<id>.mp4) — 로그 DB 오염 방지를 위한 물리 분리.
- 재생: 로그 상세의 "동영상 · 탭해서 재생" 행 → FileProvider content URI로
  시스템 플레이어 위임 (video_player 미내장 — 가장 가벼운 경로).
- 내보내기/가져오기: `.looplog`에 video 라인으로 base64 인라인 — 무손실
  원칙 유지 (큰 줄 허용, 스트리밍 설계가 한 번에 한 줄만 메모에 올림).
  파일 없이 메타만 온 동영상은 기록은 남고 본문은 건너뜀(상세 행 숨김).
- 자동 백업: videos/ 디렉터리는 자동 백업·D2D에서 제외(25MB 상한 보호) —
  수동 내보내기가 비디오의 안전망.
- 한도: 로그당 동영상 1개. 썸네일은 v1 제외(상세는 아이콘 행).
- **1분 상한 이중 검증 (2026-11-01)**: 카메라 인텐트의 EXTRA_DURATION_LIMIT는
  카메라 앱이 지키는 약속이라 서드파티 카메라가 무시할 수 있다(전세계 14개국
  출시 목표 — OEM 카메라 편차 커짐). 받은 mp4의 moov→mvhd 헤더에서 실제 길이를
  읽어 상한+2초 초과분은 첨부 거절(`lib/utils/video_duration.dart`, fail-open
  — 헤더를 못 읽는 형식은 통과). 정상 카메라는 1분에서 스스로 멈추므로 이
  메시지는 보이지 않는다. hi·it는 기존 video 문구가 누락돼 한국어 폴백이던 것도
  함께 채움.
