## Loop 통합 (2026-08-31 결정)

"포크"라는 개발 용어는 비개발 사용자에게 안 맞고, 앱의 정체성은 Loop 하나.
이어쓰기(포크) + 한 번 알림 + 반복을 **Loop 한 기능으로 통합**했다.

- 개념: Loop = "이 로그로 다시 돌아오기".
  - 지금 돌아오기 = 이어쓰기 (기존 포크)
  - 나중에 돌아오기 = 알림 옵션 — 한 번 / 반복 (반복은 발화마다 이어쓰기 자동 생성)
- 로그 메뉴 7개 → 4개: `편집 / 시간 변경 / ↩ Loop / 삭제`
  (이어쓰기·알림 예약·반복 설정·반복 중지 항목 제거)
- 통합 Loop 시트 (`loop_sheet.dart`):
  - 거는 모드 (루프 없음): 미리보기 + [지금 이어쓰기] + "다시 알려줘"(한 번/반복) + [Loop 걸기]
  - 정보 모드 (루프 있음): 주기·다음 발화·N회째 + [원본으로 이동] + [지금 이어쓰기] + [루프 중지]
  - 반복 발화 로그의 칩("Loop N회째")과 원본 칩(주기 라벨) 탭 → 정보 모드.
    기존 "탭 = 곧바로 중지"에서 시트 경유로 변경 (실수 방지 + 상태 확인).
- 실시간 정산: `settleRepeats()`를 시작 시 1회만 돌리던 것 → 포그라운드 1분 타이머 +
  lifecycle resumed 에도 실행. 앱을 켜둔 채로도 다음 발화가 제자리에 생긴다.
- 용어 정리: UI에서 "포크" 표기 전부 제거 (이어쓰기/Loop로). 데이터 모델(parentId,
  repeatRuleId)은 그대로 — 표현층만 통합.

## 루프 보기 (2026-08-31 결정)

- **루프 사슬**: 최상위 원본 → 루프 → 루프의 루프 → … → 지금 로그.
  `parentId` 사슬을 따라간다 (DB `lineage(id)`).
- **진입** (사용자 결정: 탭 → 작은 시트):
  - 빈 루프 도착 로그(반복·단발 모두) 탭 → 시트 [↩ 루프 보기 / ✍ 작성하기]
  - 작성된 포크는 ⋯ 메뉴의 "루프 보기" (포크에만 표시)
- **화면**: 타임라인 대신 사슬만 시간순 표시. 맨 위에 라벤더 필
  ("루프 보기 · 되돌아가기") — 탭하면 전체 타임라인으로 복귀.
  날짜 이동과는 동시에 쓰지 않는다(진입 시 해제). 페이지 나눔 없음.

## 백그라운드 발화 신뢰성 (2026-08-31)

- **정확 알람 권한**: Android 14+ 기본 거부 → init에서 requestExactAlarmsPermission
  (허용됐으면 화면 안 열림). 예약 실패 시 inexact 폴백 — 몇 분 늦어도 울림.
- **알림 채널**: 매번 지우던 버그 수정 — 지우면 이미 예약된 알림이 발화 시점에
  채널이 없어 조용히 누락된다(특히 재예약 안 하는 단발). 이후엔 채널 id를
  올리는 방식으로만 설정 변경.
- **단발 루프 포크**: 발화 시각이 지나면 빈 포크를 발화 시각대에 생성
  (반복과 동일). 앱 시작·1분 타이머·복귀 때마다 정산.

## 망각곡선 루프 (2026-08-31 결정)

"루프가 1번 돌아왔으면 다음엔 더 긴 간격으로" — 에빙하우스 망각곡선을
한 번 알림의 기본 간격에 적용했다.

- **사다리**: 10분 → 1시간 → 1일 → 1주 → 1달 (5단계).
  기존 빠른 선택 칩에 1달을 추가하고 순서를 곡선과 맞췄다.
- **버튼과 적용값이 함께 변한다**: Loop 시트는 loop_count N에 따라
  N+1번째 간격 칩이 기본 선택되고, 큰 시각 표시(실제 걸리는 값)도
  그 간격에서 시작한다. 다른 칩/직접 선택은 언제나 가능.
- **루프 카운트**: 단발 루프 발화마다 원본 +1 (v6 `loop_count` 컬럼).
  발화로 생긴 포크는 카운트를 이어받아 태어나므로 포크에서 다시 걸어도
  곡선이 이어진다. 발화 전 "지금 이어쓰기"로 소비해도 +1.
- **힌트 문구**: 시트 상단에 "망각곡선 {n}번째 복습 · 추천 {간격}" 표시.
- **끝에 도달하면**: 1달을 유지한다 (반복 규칙 전환은 제안하지 않음).
- **크래시 수정**: "매일" 프리셋에서 timeOfDay에 시간만 저장해
  `RangeError (length)`가 나던 버그 — "HH:mm" 완전형으로 저장하고
  파싱은 레거시 값("09")도 방어.

## 다가오는 루프 미리보기 · 평일 반복 (2026-10-17 결정)

- **미리보기 시트**: AppBar `↑` 아이콘 → 오늘부터 7일 창의 루프를 한 장에.
  단발 루프는 창 안 전부, 매일/평일 반복은 매 발화가 한 줄, 분/시간 반복은
  다음 발화만(7일치를 늘어놓으면 수백 줄). 행 = 시각+요일 · 원본 내용 1줄 ·
  규칙 라벨. 탭하면 그 원본 로그가 있는 날로 타임라인 이동(검색 점프 패턴).
- **빈 루프 포크 미리보기**: "비어 있음" 대신 원본(부모) 내용 앞 10자 + ….
  루프를 누르기 전에 무엇에 대한 루프인지 보인다. 부모를 모르면 기존 힌트.
- **평일 반복**: 반복 프리셋에 "평일" 추가 — 토·일·한국 공휴일(관공서 기준
  날짜표, 2026~2028)을 건너뛰고 발화 시각을 유지한다. 라벨 "평일 09:00".
