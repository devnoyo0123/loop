## 변경 내역 (개발용)

- **알람이 화면에 안 뜨던 문제 (실기기 Fold4)** — Play 전체 화면 인텐트 선언이 '기타'라 Android 14+에선 설치 시 USE_FULL_SCREEN_INTENT가 꺼져 있고, 재설치·복원 뒤에도 꺼진다 → 소리만 나고 화면 없음. `AlarmPermissionGuard`: 다가오는 알람이 있는데 권한 없으면 안내(시작·복귀·시트 닫힘), 알람을 걸 때·발화 체험 때는 즉시. 알림: 탭 = 알람 화면, 권한 없으면 '전체 화면 켜기' 버튼 + 안내문(`AlarmPresentation`, JVM 테스트).
- **루프 보기 알약이 첫 카드를 가리던 문제** — `PillHeaderLayout`(알약이 자기 줄을 차지).
- **MCP(Mac에서 검색) 출시 제외** — `kMcpEnabled`(release=false) + `src/release/AndroidManifest.xml`에서 dataSync 권한·서비스 제거. 개발(debug) 빌드엔 그대로.

- **Loop 공유를 모든 기록에** — 메뉴 노출 조건(`_log.isFork`)을 제거. 기존엔 이어진 기록(포크)에서만 보여 혼자인 기록·막 건 루프(발화 전)·사슬 원본에서는 공유할 수 없었다. 보내는 로직은 원래 원본 1개짜리 사슬을 지원(`id = root OR path LIKE root/%`).
- 메뉴·시트 이름 "사슬 공유" → **"Loop 공유"** (8개 언어, 키는 유지: `shareChainAction`/`shareChainTitle`).
- 개인정보처리방침 v1.2 — 메뉴 이름·전달 범위 문구 갱신.
- 테스트: 혼자인 기록 공유 왕복, 막 건 루프 이어받기, 모든 기록 메뉴 노출. 기존 flaky 테스트(밀리초 저장 vs 마이크로초 비교) 수정.
