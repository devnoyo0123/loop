## 변경 내역 (개발용)

- **Loop 사용법(그림 안내)** — 설정 › 앱 정보 › Loop 사용법. `GuideScreen` + `guide_content.dart`(11개 항목, 알람은 그림 2장). 그림 `assets/guide/{ko,en}/*.webp` 24장(약 792KB, 에뮬레이터+데모 DB 캡처 — 개인 기록 없음). 한국어는 한국어 그림, 그 밖의 언어는 영어 그림. 글은 8개 언어 ARB `guide*`. 테스트 `test/guide_test.dart`(8).
- **공개 사용법 페이지** — https://devnoyo0123.github.io/loop-guide/ (`tool/build_guide_page.py`로 생성). 스토어 en-US 전체 설명 끝에 링크(2026-11-01 검토 제출).
- **알람 화면 버튼** (loop-62) — `res/drawable/alarm_btn_snooze.xml`·`alarm_btn_confirm.xml` 신규, `layout/alarm_activity.xml` 두 버튼에 배경·minHeight 52dp·stateListAnimator @null·textAllCaps false.
- **MCP(Mac에서 검색)는 계속 출시 제외** — `kMcpEnabled`(release=false) + `src/release/AndroidManifest.xml`. FGS dataSync 선언·개인정보처리방침 반영 전.
