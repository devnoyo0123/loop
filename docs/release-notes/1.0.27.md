# Loop 1.0.27 (versionCode 31) — 출시 노트

> 2026-11-18 · AAB: `build/app/outputs/bundle/release/app-release.aab` (업로드 키 CN=Loop)
> 게시: 프로덕션 100% 전체 출시, 2026-11-18 검토 제출 완료 (게시 개요 "검토 중인 변경사항" — 관리형 게시 꺼짐 → 승인 시 자동 게시). 백업: work/backups/aab/loop-1.0.27-31.aab
> 제출 시 Google 사전 검사 이슈 1개 무시 처리: play-services-nearby(사슬 공유)가 병합하는 Wi-Fi 권한 3개가 `android.hardware.wifi` 필수로 암시 → Wi-Fi 없는 기기 설치 제한 경고. 매니페스트는 1.0.26과 동일(변경 없음). **1.0.28 과제: 매니페스트에 `<uses-feature android:name="android.hardware.wifi" android:required="false"/>` 추가**
> Play Console "이 버전의 새로운 기능" — 언어별 500자 이내.
> 핵심: 다가오는 루프(반복 회차 포함) + MCP `upcoming_loops`(PC 연결) + 힌디어·이탈리아어.
> 신규 권한 없음 (1.0.26 AAB 빌드 이후 매니페스트·Kotlin 변경 없음 — Dart/l10n/에셋 전용).
