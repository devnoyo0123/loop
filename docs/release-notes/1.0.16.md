## 변경 내역 (개발용)

### 새 기능 — 사슬 근거리 공유 (docs/share-design.md §6)
- 전송 계층: Google Nearby Connections **직접 연동**(Kotlin `NearbyBridge`) — 플러그인 제거. STREAM 페이로드 + 크기 헤더, 받는 쪽은 앱 캐시 `share/`에 직접 쓴다(공용 Downloads 미사용).
- 보내기: 발견 목록에서 탭해 선택(자동 연결 없음), 진행률·속도·남은 시간, 블루투스 속도면 Wi-Fi 안내, 60초 무진행 시 실패(전체 시간 상한 없음), [다시 찾기].
- 받기: 설정 › 가까운 기기에서 받기(켤 때 권한 요청, 끄면 기억), 권한이 이미 있으면 앱 시작 시 조용히 대기, 어느 화면에서든 "○○님이 보내는 중 · 42%" 스낵바, 중단 알림, 60초 무진행 시 정리.
- 권한: API별 조합(33+ 블루투스 3종 + 근처 Wi-Fi 기기 / 31–32 + 위치 / ≤30 위치). 표시명 기본값 = 기기 이름.
- 파일 수명: 사건 즉시 삭제 + 주기 청소(시작·복귀·세션 종료·30분) + 설정 수동 정리.

### 수정
- **광고 SDK 초기화 경쟁으로 인한 시작 직후 ANR** — 초기화 완료 전 NativeAd 생성 시 메인 스레드가 SDK 락(WebView 준비)을 기다림. 광고 로드를 `AdsService.ready` 이후로. (play-services-ads 25.4.0 ANR 트레이스로 확인)
- Nearby 일반 권한(ACCESS_WIFI_STATE 등) maxSdk 제거 — 공식 문서 표와 달리 API 35에서도 요구됨(에뮬레이터 확인).

### 검증
- `flutter analyze` 0건, `flutter test` 346 통과, Kotlin JVM 23 통과(`./gradlew :app:testDebugUnitTest`).
- 에뮬레이터 API 35: 1.0.14 → 1.0.16 덮어쓰기 설치(데이터 보존 확인), 콜드 스타트 3회 ANR 0, 설정 신규 행 표시, 받기 권한 요청 → BLE·BT Classic·Wi-Fi LAN 광고 시작 → 끄기 동작.
- **미검증(실기기 2대 필요)**: 실제 전송·Wi-Fi Direct 승격·제조사별 동작 — 내부 테스트 트랙에서 확인.
