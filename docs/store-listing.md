# Loop — 스토어 등록 문구 (다국어)

> Play Console 등록 때 복붙용. 기본 목록 언어 = **영어(en-US)** 권장(글로벌 노출),
> 한국어(ko-KR)는 "번역 추가"에서 등록. 앱이 지원하는 ko/en과 목록 언어를 맞췄다.
> 나중에 앱에 언어를 추가하면(예: ja) 여기에 목록 번역을 추가하는 방식으로 확장.
> 글자수: 제목 ≤30, 짧은 설명 ≤80, 전체 설명 ≤4,000

## 1. 기본 목록 — English (en-US)

### Title ⚑

```
Loop — Daily Timeline Log
```
(후보: "Loop — Your day, in order", "Loop")

### Short description (80자)

```
Log your day in order. Continue a past thought, and loops bring it back to you.
```

### Full description

```
We believe the order your day flows in is the answer.

Loop has no titles, no folders, no categories. Write what's on your mind right
now — it lands at this very moment. Read it later, and the whole day flows
back in exact order.

▌ Continue writing (fork)
When yesterday's thought leads somewhere new today, continue writing on that
log. The lineage stays attached, so the flow never breaks.

▌ Loop reminders
Set a loop on any log. When the time comes, it comes back to you — with sound,
until you confirm it. One thought that won't slip away.

▌ Repeats
"Every 10 minutes", "Every night at 9" — a repeat spawns a fork each time it
fires, and the card shows how many times it has come around.

▌ Fast search
Full-text search across content and places, instantly. Switch between
relevance and newest-first.

▌ Jump to a date
Open any past day straight from a calendar.

▌ Photos, place & weather — automatically
Attach a photo, and the place and weather at that moment are quietly captured
alongside. Coordinates are never shown on screen.

▌ Your data stays yours
Everything lives on your phone only. Nothing is sent to a server.
Export your entire log as a .looplog file from Settings for backup.
(Regular exports are recommended for records you care about.)

Write down the thought you'd otherwise let drift away.
```

기록이 쌓이는 순서, 그대로가 답이라고 믿습니다.

Loop는 제목·폴더·분류 없이, 지금 떠오른 생각을 지금 시각에 그냥 적습니다.
나중에 읽으면 그날의 흐름이 시간순으로 고스란히 돌아옵니다.

▌ 이어쓰기 (포크)
어제 쓴 생각에 오늘 다시 생각이 이어지면, 그 로그에 이어쓰기를 하세요.

▌ 루프 알림

▌ 빠른 검색
전문 검색으로 내용·장소를 즉시 찾습니다. 관련도순·최신순 전환 지원.

▌ 날짜 이동

▌ 사진·위치·날씨 자동 기록
사진을 첨부하면, 저장한 시점의 장소와 날씨가 조용히 함께 기록됩니다.
좌표는 절대 화면에 표시되지 않습니다.

▌ 내 데이터는 내 손에
모든 기록은 휴대폰 안에만 저장됩니다. 서버로 전송되지 않아요.
설정에서 전체 기록을 .looplog 파일로 내보내 보관할 수 있습니다.
(중요한 기록은 주기적으로 내보내기 백업을 권장합니다)

지금 떠오른 생각을, 흘려보내지 말고 남겨두세요.

## 3. 일본어 (ja-JP)

### Title

```
Loop — 時間順の一日ログ
```

### Short description (80자)

```
思った順に積もる一日ログ。過ぎた思考は続き書きでつなぎ、ループ通知でまた戻る。
```

### Full description

```
一日が流れていく順番のままが、答えだと信じています。

Loop にタイトルもフォルダも分類もありません。いま浮かんだ思考を、いまの時刻にただ書く。
後で読み返せば、その日の流れが時間順にそのまま蘇ります。

▌ 続きを書く（フォーク）
昨日の思考に今日また考えがつながったら、そのログに続きを書こう。
どこから続いたかは系譜が残るので、流れが途切れません。

▌ ループリマインダー
ログにリマインダーをかけると、決まった時刻に音と一緒にまた会いに来ます。
確認するまで、忘れた考えにはさせない。

▌ 繰り返し
「10分ごと」「毎晩9時」と繰り返しをかけると、発火のたびに続き書きが自動生成されます。
何回戻ってきたかはカードですぐわかります。

▌ 高速検索
全文検索で内容・場所を即座に検索。関連度順・新着順の切り替えに対応。

▌ 日付へ移動
カレンダーから過去のどんな日でもすぐ開けます。

▌ 写真・位置・天気を自動で記録
写真を添付すると、保存した時点の場所と天気が静かに一緒に記録されます。
座標が画面に表示されることはありません。

▌ データはあなたの手の中
すべての記録はスマホの中だけに保存され、サーバーには送信されません。
設定から全記録を .looplog ファイルとしてエクスポートして保管できます。
（大切な記録は定期的なエクスポートを推奨します）

いま浮かんだ思考を、流してしまわずに残しておこう。
```

## 4. 중국어 간체 (zh-CN)

### Title

```
Loop — 按顺序记录每一天
```

### Short description (80자)

```
按顺序积累的一天记录。用续写接住流逝的想法，让循环提醒带你回来。
```

### Full description

```
我们相信，一天原本流过的顺序，就是答案。

Loop 没有标题、文件夹和分类。此刻浮现的想法，就写在此刻。
以后重读时，那一天的流动会按时间顺序原样回来。

▌ 续写（分支）
昨天的想法今天有了新的延续，就在那条记录上续写。
续写自哪里都有脉络可循，思路不会断线。

▌ 循环提醒
给记录设一个循环，到了设定的时间它会带着声音回来。
在你按下"知道了"之前，这个想法不会被忘记。

▌ 重复
设成"每10分钟""每晚9点"，每次触发都会自动生成续写。
卡片上能直接看到已经转回来多少次。

▌ 快速搜索
全文搜索内容与地点，瞬间出结果。支持相关度、最新排序切换。

▌ 跳转到日期
用日历直接打开过去的任何一天。

▌ 照片、位置、天气自动记录
附上照片时，当时的位置和天气会安静地一并记录。
坐标绝不会显示在屏幕上。

▌ 数据掌握在你手里
所有记录只保存在手机里，不会上传服务器。
在设置中可以把全部记录导出为一个 .looplog 文件保存。
（重要的记录建议定期导出备份）

此刻浮现的想法，别让它溜走。
```

## 5. 스페인어 (es-ES)

### Title

```
Loop — Tu día, en orden
```

### Short description (80자)

```
Registra tu día en orden. Continúa un pensamiento y los bucles te lo devuelven.
```

### Full description

```
Creemos que el orden en el que fluye tu día es la respuesta.

Loop no tiene títulos, carpetas ni categorías. Escribes lo que te viene a la
mente ahora mismo, y queda en este preciso momento. Cuando lo releas, todo el
día vuelve fluyendo en su orden exacto.

▌ Continuar escribiendo (fork)
Cuando el pensamiento de ayer sigue hoy, continúa ese registro.
El linaje queda marcado: el hilo nunca se rompe.

▌ Avisos de bucle
Ponle un bucle a un registro y volverá a ti a la hora fijada, con sonido,
hasta que lo confirmes. Un pensamiento que no se escapa.

▌ Repeticiones
"Cada 10 minutos", "cada noche a las 9" — cada disparo crea un fork
automático, y la tarjeta muestra cuántas veces ha vuelto.

▌ Búsqueda rápida
Búsqueda de texto completo en contenido y lugares, al instante. Cambia entre
relevancia y más recientes.

▌ Saltar a una fecha
Abre cualquier día pasado directamente desde el calendario.

▌ Fotos, lugar y tiempo — automáticamente
Adjunta una foto y el lugar y el tiempo de ese momento se guardan en silencio.
Las coordenadas nunca se muestran en pantalla.

▌ Tus datos son tuyos
Todo vive solo en tu teléfono. Nada se envía a ningún servidor.
Exporta todo tu registro como un archivo .looplog desde Ajustes.
(Se recomienda exportar con regularidad los registros importantes.)

Escribe el pensamiento que dejarías irse.
```

## 등록 방법 (Play Console)

1. 스토어 등록 정보 생성 시 **기본 언어 = 영어(미국)** 선택 → 위 1번 붙여넣기
2. "번역" → "자체 번역 관리" → 아래 언어 추가 → 각 섹션 붙여넣기:
   한국어(ko-KR), 일본어(ja-JP), 중국어 간체(zh-CN), 스페인어(es-ES, 원하면 es-419 복제), 베트남어(vi)
3. 그래픽(아이콘·기능 그래픽·스크린샷)은 언어 공통 — 기본 목록에만 올리면 됨
   (언어별 그래픽도 가능하지만 불필요)
4. ⚑ 출시 국가: 글로벌 — 앱 UI도 6개 언어(ko/en/ja/zh/es/vi)라 목록과 일치

## 카테고리 / 태그

- 카테고리: 생산성 (또는 라이프스타일) ⚑
- 콘텐츠 등급: 전체 이용가
- 광고 포함: **있음** (AdMob 예정이므로)

## 스크린샷 촬영 계획 (개인로그 보호)

폰에는 실제 개인 기록이 있어 그대로 캡처하면 안 됨. **에뮬레이터**에서 진행:

1. 에뮬레이터 생성 (avdmanager, API 34+)
2. debug APK 설치
3. 데모 DB 주입 — 데모 .looplog를 만들어 `run-as com.loop.loop`로
   databases/loop.db 교체 (debug 빌드라 run-as 가능)
   데모 내용: 일상적 예시 로그 10~15개 (이어쓰기 1체인, 반복 카드, 사진 1장)
4. 촬영 장면 (9:16, 최소 4장 권장):
   - 타임라인 전체 (가장 예쁜 화면)
   - 상세 카드 펼침 (사진+날씨+이어쓰기 계보)
   - 검색 화면 (관련도순 + 하이라이트)
   - 작성창 (이어쓰기 배너)
5. `adb exec-out screencap -p > shots/01_timeline.png`

※ 스크린샷 언어: 폰 언어를 영어로 두고 한 세트, 한국어로 한 세트면 언어별 목록에
각각 넣을 수 있음. 최소한은 한국어 세트 1개(기본 목록 공용)로 시작 가능.
